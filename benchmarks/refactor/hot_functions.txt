# Hot functions for asmdiff.py --watch: the code that runs per line,
# per buffer or per file in the benchmark scenarios.  A refactor that
# changes the machine code of any of these needs an A/B timing run.
# Each line is a function name or a shell pattern; a name also matches
# its GCC clones (NAME.part, NAME.isra, NAME.constprop, NAME.cold).
# A function that a build inlines everywhere has no code of its own and
# shows up only through its callers, so the callers that inline the
# per-chunk and per-file loops are listed too; asmdiff.py names the
# patterns that match no out-of-line function.
