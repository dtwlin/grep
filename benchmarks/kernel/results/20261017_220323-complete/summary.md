# Linux Kernel-Tree 3-Way Benchmark Results

> Multi-threaded GNU `grep` fork (G1) vs Stock upstream GNU `grep` (G0) vs `ripgrep` 15.1.0 (R0) vs `ugrep` 7.8.5 (U0) vs Distro GNU `grep` 3.12 (G2) vs `git grep` (X1).

## 1. System & Binary Provenance

- **Host**: AMD EPYC 7B13 Zen 3 (128 logical cores), 236 GiB RAM
- **Kernel**: `7.1.6`
- **THP**: `[always] madvise never`
- **Corpus**: Linux kernel clean working tree (96,034 files, 1.64 GB), `linux-all.c` (1.45 GB)
- **Isolation**: All 128 logical CPUs (2 NUMA nodes, CPUs 0-127)
- **Run Note**: Complete 59-scenario Linux kernel benchmark (G0, G1, R0, U0 in one session) with fair thread-matched comparisons
- **G0**: Upstream GNU grep baseline `3.12.41` (1 thread)
- **G1**: Our multi-threaded fork (`76d3503`, default 33 threads)
- **R0**: Stock ripgrep 15.1.0 (default 13 threads)
- **U0**: Stock ugrep 7.8.5 (default 13 threads)
- **G2**: Distro GNU grep 3.12 (1 thread)
- **X1**: Git grep 2.56.0 (default 129 threads)
